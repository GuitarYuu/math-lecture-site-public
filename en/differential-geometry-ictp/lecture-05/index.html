    Lecture 5¶

    Chapter: Regular Surfaces

    Example

    \(S^1(r)\) circle of radius \(r(r>0)\) in the plane \(x=0\) with center \((0,a,0),(a>r)\).

    Rotate this curve around the axis \(z\),\(\{x=y=0\}.\) \(S=\{(x,y,z)\mid (\sqrt{z^2+y^2}-a)^2+x^2=r^2\}\).

    Look at \(f:\mathbb{R}^3\backslash\{z-\text{axis}\}（注：I've taken out the z-axis in order to have a differentiable function. Otherwise, since I have a square root here, I would end up in problems of differentiability.）\to\mathbb{R}\quad (x,y,z)\mapsto (\sqrt{z^2+y^2}-a)^2+x^2\).

    \(S=f^{-1}(r^2)\).

    Is \(r^2\) a regular value for \(f\)? \(df_p,\forall p\in f^{-1}(r^2)\).

    \(\frac{\partial f}{\partial x}=2x,\frac{\partial f}{\partial y}=\frac{2y(\sqrt{z^2+y^2}-a)}{\sqrt{z^2+y^2}},\frac{\partial f}{\partial z}=\frac{2z(\sqrt{z^2+y^2}-a)}{\sqrt{z^2+y^2}}\).

    \(r^2\) is a regular value.

    Definition

    \(S\) is a regular surface, \(\mathcal{O}\) is an open set of \(\mathbb{R}^3\).

    A) \(F:S\to\mathbb{R}^n\) is differentiable if for any local chart of \(S, X:U\to S, F\circ X:U\to\mathbb{R}^n\) is differentiable.

    B) \(f:\mathcal{O}\to S\) is differentiable if \(f:\mathcal{O}\to\mathbb{R}^3\) is differentiable.

    C) \(S_1\) ia another regular surface, \(f:S\to S_1\) is differentiable if \(f:S\to\mathbb{R}^3\) is differentiable（注：in the sense of A)）.

    \(f,g:S\to\mathbb{R}^n\) are differentiable, then \(f+g,\lambda f,<f,g>\) are differentiable.

    Example

    1) \(F:\mathcal{O}\to\mathbb{R}^3\) is differentiable and \(S\subset\mathcal{O}\). \(F\bigg|_{S}\) is differentiable. In particular, \(i:S\to\mathbb{R}^3\) and \(id:S\to S\) and the constants are differentiable.

    2) height function: let \(P\subset\mathbb{R}^3\) be a plane, \(p_0\in P\) and \(a\) is a normal vector to \(P\). \(S\) is a regular surface, \(h:S\to \mathbb{R}\quad p\mapsto<p-p_0,a>\) is differentiable.

    3) distance squared: \(p_0\in\mathbb{R}^3\).

    \(f:S\to\mathbb{R}\quad p\mapsto|p-p_0|^2\).

    4) distance: \(f(p)=|p-p_0|\quad\) \(f:S\to\mathbb{R}\).

    If \(p_0\notin S\), then differentiable.

    If \(p_0\in S\), then not differentiable.

    Proposition

    \(f:S\to\mathbb{R}^n\) function. If \(\forall p\in S,\exists x_p:U_p\to S\) local chart around \(p\) s.t. \(f\circ x_p:U_p\to\mathbb{R}^m\) is differentiable, then \(f\) is differentiable.

    Pf: Exercise.

    Definition

    \(S\) is a regular surface. \(p\in S\). We say that \(v\in\mathbb{R}^3\) is a tangent vector to \(S\) at \(p\) if \(\exists\alpha:(-\varepsilon,\varepsilon)\to S\) differentiable, \(\varepsilon>0\), s.t. \(\alpha(0)=p,\alpha'(0)=v\).

    The set of tangent vectors to \(S\) at \(p\) is denoted by \(T_pS\).

    Lemma

    \(X:U\to S\) is a local chart around \(p\). \(T_pS=dX_{X^{-1}(p)}(\mathbb{R}^2)\).

    Proof

    Pf: \("\supseteq"\) Let \(w\in\mathbb{R}^2\) be any vector.

    \(\beta(t)=X^{-1}(p)+tw,\beta:(-\varepsilon,\varepsilon)\to U\).

    \(\beta(0)=X^{-1}(p),\beta'(0)=w\).

    Define \(\alpha:(-\varepsilon,\varepsilon)\to S,\alpha=X\circ \beta\).

    \(\alpha(0)=p,\alpha'(0)=dX_{X^{-1}(p)}(w)\).

    \(\implies dX_{X^{-1}(p)}(w)\in T_pS\).

    \("\subseteq"\) Let \(v\in T_pS\). \(\exists\alpha:(-\varepsilon,\varepsilon)\to S,\alpha(0)=p,\alpha'(0)=v\).

    \(\alpha(-\varepsilon,\varepsilon)\subset X(U)\).

    Put \(\beta=X^{-1}\circ\alpha:(-\varepsilon,\varepsilon)\to U\).

    \(\beta(0)=X^{-1}(p)\).

    \(v=\alpha'(0)=(X\circ \beta)'(0)=dX_{X^{-1}(p)}(\beta'(0))\).\(\square\)

    The tangent space to a regular surface at any point is automatically a two-dimensional vector space.

    Corollary

    1) \(T_pS\) is a vector space.

    2) \(T_pS\) is generated by \(\{\frac{\partial X}{\partial u},\frac{\partial X}{\partial v}\}\).

    Figure: The warning of drawing tangent space

    Narrative

    General warning, when you draw pictures, so you draw your surface, and both me and books and whatever, you will always find a picture of this form. So this is the surfaces, this is the point \(p\) (fig:The warning of drawing tangent space), and everybody will draw something like this as the tangent space. You image this two-dimensional vector space translated with origin at the point \(p\). The truth is not this one. This is just to fix in your mind that this is the tangent space at the point \(p\). If you really want to draw which space it is, which set it is, since it's vector space, it's better passed through the origin. So it's really the translation of what you draw in this geometric way here. We will always make this mistake happily.

    Exercise

    1) \(\mathcal{O}\) open set of \(\mathbb{R}^3, f:\mathcal{O}\to\mathbb{R}\) is a differentiable function. \(a\) is a regular value of \(f\). \(S=f^{-1}(a)\) is a regular surface.

    Claim: \(T_pS=ker((df_p):\mathbb{R}^3\to\mathbb{R})\).

    Pf: \("\subseteq"\) \(v\in T_pS\implies \exists\alpha:(-\varepsilon,\varepsilon)\to S\) s.t. \(\alpha(0)=p,\alpha'(0)=v\implies f(\alpha(t))=a,\forall t\implies df_p(v)=\frac{d}{dt}\bigg|_{t=0}(f(\alpha(t)))=0\).

    We know by general theory that \(ker((df_p):\mathbb{R}^3\to\mathbb{R})\) is two-dimensional, and we just proved that \(T_pS\) is contained in \(ker((df_p):\mathbb{R}^3\to\mathbb{R})\). But \(T_pS\) is also two-dimensional by general theory. So this is a two-dimensional vector space contained in a two-dimensional vector space. So there is nothing to prove. They have to be the same.\(\square\)

    2) \(S_a^2(r)=\{p\in\mathbb{R}^3\mid |p-a|^2=r^2\}\).

    \(f(p)=|p-a|^2,S_a^2(r)=f^{-1}(r^2)\).

    \(df_p(v)=\frac{d}{dt}\bigg|_{t=0}<\alpha(t)-a,\alpha(t)-a>=<v,p-a>+<p-a,v>=2<v,p-a>\).

    \(T_pS_a^2(r)=ker\ df_p=\{v\in\mathbb{R}^3\mid<v,p-a>=0\}\).
